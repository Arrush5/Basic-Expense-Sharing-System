# Basic Expense Sharing System

A simple Python application that helps users **track shared expenses** and fairly split costs among a group of people. This system makes it easy to record individual payments, calculate who owes what, and settle group balances.

---

## Project Objective

The objective of this project is to:
- Simplify the process of tracking shared expenses
- Automatically compute balances owed by each participant
- Help groups settle expenses fairly and efficiently
- Provide a clear record of transactions

This tool can be used for shared trips, household bills, events, and group purchases.

---

## Tech Stack

- Python
- Command-line interface (CLI)
- Standard Python libraries

*(No external dependencies required — runs with pure Python.)*

---

## Features

- dd new expenses with payer and participants
- Automatically split costs evenly among participants
- Show net balances owed by each person
- Support multiple transactions
- Display a summary of expenses

---

## Installation & Setup
1. Clone the repository: git clone https://github.com/Arrush5/Basic-Expense-Sharing-System.git

---

## How to Run
1. Run the main Python script: python main.py
2. Follow the interactive prompts to:
  - Enter participants
  - Enter expenses
  - View expense summaries
  - Check who owes money and how much

---

## How It Works
1. You enter the names of participants.
2. For each expense:
  - Enter the payer
  - Enter the amount
  - Enter participants involved in that expense
4. The system calculates how much each person owes or is owed.
5. Final balance sheet shows who should pay whom.

---

## Use Cases
- Group trips
- Splitting household bills
- Sharing event or party expenses
- Fair cost-sharing among roommates or friends
